# 04 · 核心基础设施层

## 1. 数据库 `core/database.py`

### 连接管理 `DatabaseManager`（:183-313）
- **每库一个连接**：`dict[str, sqlite3.Connection]`，`check_same_thread=False`（跨线程使用由应用层锁保护）
- `open_library`（:194-225）：旧版数据目录迁移 → `library_data_dir().mkdir` → 建连 + `executescript(_SCHEMA)` + `migrate_db` → WAL 模式 → 缩略图目录
- 关闭协调（`close` :243-263 / `close_library` :266-293）：先标记所有写状态 `closed`（拒绝排队中的写者）→ 在全局 `_WriteGate.write()` 下逐个关连接

### 并发写控制（三层锁）
```
全局 _WriteGate（database.py:39-78）  —— 读写门闩：关库前拒绝/等待所有写者
每连接 _ConnectionWriteState.lock    —— 该连接的串行写锁（owner_thread/depth 记录）
模块级 _connection_locks registry    —— 按 id(conn) 绑定写状态；未托管连接回退共享锁
```
- `db_write_lock(conn)`（:318-357）：新代码必须传 conn 获得绑定锁；无参形式是遗留重入锁。写锁等待/持有时间记录到性能遥测（`_record_write_lock`）
- 写者所有者跟踪（owner_thread/owner_depth）实现**可重入**：同一线程可嵌套取锁

### 路径元数据迁移 `migrate_path_metadata`（:400-482）
文件移动后：`file_tags`（INSERT OR IGNORE + 删除旧路径，LIKE ESCAPE 防通配符注入）→ `file_meta`（合并策略：非空优先）→ `thumbnail_cache`（cache_key 重算 + 物理文件改名/删除）。全程单事务。

### 孤儿清理 `clean_orphan_dirs`（:300-311）
删除 RuntimeData 下超过 7 天、不属于已知库的目录（防残留垃圾）。

## 4. 主题系统 `core/themes.py` + `theme_loader.py`

### 加载（themes.py:103-116，模块导入时执行）
`_load_all_themes()`：ThemeLoader 扫描 `Assets/Themes/` → `_merge_theme` 校验必填 token（base/panel/header/border/heading/body/muted/accent/success/warning/danger/favorite/recent + name/colors）→ 扩展 token 兜底（on_accent/hover_overlay/scrollbar_* 等 13 个）→ 存 `_THEMES` 字典

### 热重载
`ThemeLoader.watch_changes()`（theme_loader.py:153-159）：`QFileSystemWatcher` 监听主题目录 → 文件/目录变化 → 重新解析 → `themes_changed` 信号 → `reload_themes()` → 全局刷新

### 样式
`stylesheet()`（themes.py:300-428）：缓存全局 QSS（主题名变化才重建），覆盖 QMainWindow/QDockWidget/QMenu/QTab/QScrollBar/QPushButton 等全套组件，统一走 `scaled_px` 缩放、`alpha()` 透明度工具。背景图开启时面板/标题栏半透明。

### 背景效果 API（themes.py:262-299）
`bg_enabled/bg_image/bg_effect/bg_effect_intensity/bg_panel_opacity...`：AppSettings 覆盖优先，主题 JSON `background` 段兜底。

### 自定义主题
`ThemeLoader.create_custom_theme`（U_ 前缀 JSON）/`delete_custom_theme`/`export_theme`。

## 5. 缓存与存储

| 模块 | 说明 |
|---|---|
| `cache.py` | `DictCache` / `LRUCache`（max_size）/ `TTLCache`（ttl+size），全部线程安全 |
| `json_store.py` | JSON 持久化基类：惰性加载、原子写、dirty 标志、`_on_loaded`/`_on_before_save` 钩子；`SidebarFavorites`/`SidebarRecentFolders` 继承它 |
| `directory_cache.py` | SQLite 版目录缓存：`get/set/get_batch(500/批)/invalidate/clear`；mtime 失效 |
| `tag_store.py` | 遗留 TagStore（委托 TagRepository + resolve 缓存 10000 条），已标记废弃 |
| `tag_library.py` | 多语言同义词表（~70 个规范标签，中/日/英别名，Pixiv 风格），持久化 `Shared/tag_library.json`，`canonical()` 统一规范化 |
| `library_manager.py` | 库记录 CRUD（uid/name/path/last_opened），存 AppSettings `library_records` |
| `project_data.py` | 遗留 ProjectData（notes/urls/目录大小），已废弃，迁移到 MetadataService |

## 6. 路径解析 `core/path_resolver.py`

```
runtime_root()  → exe 旁 RuntimeData（frozen）或仓库根/RuntimeData（开发）
shared_dir()    → RuntimeData/Shared（settings、插件、cloudflared 缓存）
library_data_dir(root) → {库名}_{sha256(resolved)[:10]}
thumb_dir()     → 库数据目录/.thumbnails
db_path()       → 库数据目录/assetmanager.db
themes_dir()    → PyInstaller _MEIPASS 或 Assets/Themes
```

## 7. 辅助设施

- `performance.py`：`PerformanceRecorder`（默认关闭，环形 200 条），`record(name, ms, session_token, path, attributes)`；`measure()` 上下文；`recent()` 只读快照。**全项目遥测统一走它**（目录列表/搜索/文件命令/DB 锁等待/LAN 路由）
- `signal_bus.py`：Qt 信号总线（directory_changed/file_focused/theme_changed/language_changed/ui_scale_changed/sidebar_depth_changed），**仅限展示层协调**（docstring 明确与领域事件分工）
- `crash_handler.py`：excepthook → 轮转日志（`crash.log`）→ 记录堆栈
- `ui_scale.py`：`get_ui_scale()`（AppSettings `ui_scale`）→ `scaled_px/scaled_pt`
- `color_utils.py`：hex↔rgb、alpha、lighten/darken、对比度
- `format_utils.py`：`format_size`（KB/MB/GB 中文单位风格）、`CATEGORY_MAP`（扩展名→分类）
- `bg_effects.py`：`apply_blur`（QGraphicsBlurEffect 渲染）/ `apply_mosaic`（像素块化）
- `tool_scheduler.py`：外部工具注册表（JSON 持久化）+ `run_tool` 拉起外部程序
- `singleton.py`：`ThreadSafeSingleton`（带锁的类级单例注册表）
- `protocols.py`：`TagStoreProtocol` 等结构化协议（供兼容适配）

| 模块 | 类 | 职责 |

插件目录：`RuntimeData/Shared/plugins/`（或仓库根 `Plugins/Addons/`），`plugin.json` 清单。加载时调用入口模块的 `register(host)`。

## 9. 数据流要点

- 写操作**必经** `db_write_lock(conn)`；读操作直接 execute（SQLite WAL 下多读并行）
- 缓存失效靠 **mtime 对比**（directory_cache / 目录大小）；**当前浏览目录**有 QFileSystemWatcher 自动刷新（_navigation.py:48-66），其余目录变更需进入触发
- 主题/设置变更 → 信号总线广播 → 各面板自行刷新
- 性能遥测全链路打点但不阻塞业务（所有 record 调用 try/except 包裹）
