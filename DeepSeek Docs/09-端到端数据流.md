# 09 · 端到端数据流

以下六条链路覆盖产品核心场景，从入口到持久化逐跳追踪。

## 链路 1：打开库 → 浏览目录（桌面端）

```
用户选库（StartupWindow）→ library_opened 信号
 └→ MainWindow._workspace.add_library(path)
      └→ LibraryService.open_session → DatabaseManager.open_library（建库/迁移）
      └→ bootstrap.runtime_for(session) → LibraryRuntime（缓存单例，epoch+revision）
      └→ _apply_scoped_services → 各面板 set_scoped_services
侧边栏点击目录 → signal_bus.directory_changed → FileListPanel.navigate_to
 └→ FileSystemModel._ScanTask（QThreadPool）os.scandir
      └→ 过滤/排序/目录摘要（DirectoryCache 命中或扫描）
 └→ 行插入信号 → 网格渲染 → ThumbnailLoader 异步缩略图
选中文件 → signal_bus.file_focused → InfoPanel.update_info（后台 _FileInfoTask）
 └→ InfoController.get_file_info
      ├→ MetadataService.get_metadata（标签/备注/URL）
      └→ PluginMetadataRepository（插件字段）
```

## 链路 2：打标签/写备注 → 桌面与浏览器实时同步

```
InfoPanel 标签输入 → InfoController.add_tag → TagService.add_tag
 └→ canonical 规范化（"贴图"→"Texture"）
 └→ TagRepository.add_tag（db_write_lock 写 file_tags）
 └→ EventBus.publish(AssetTagsChanged{library_root, session_token, file_path, new_tags})
      ├→ TagTree 面板（_event_bridge）刷新标签树
      └→ RuntimeEventRouter._on_event
           ├→ 校验 session_token 匹配 + 路径在库内
           ├→ runtime.next_revision() → revision+1
           └→ 广播 InvalidationEvent(epoch, revision, [metadata,tags,project_detail,home], [路径])
                └→ lan/api.py on_invalidation → ws_manager.broadcast("projection_invalidated")
                     └→ 浏览器 WebSocket 收到 → 按 domains 失效缓存 → 重取受影响 API
```

## 链路 3：文件移动/删除 → 元数据与索引一致性

```
右键移动 → ActionsMixin._paste → FileOperationService.move_to_directory
 └→ shutil.move
 └→ _migrate_metadata（file_tags/file_meta/thumbnail_cache 三表重映射，单事务）
 └→ _refresh_after_move（assets 索引：删旧条目 + 重建父目录 + 全树重建）
 └→ EventBus.publish(FileRenamed + FileSystemChanged)
      └→ RuntimeEventRouter → 桌面视图刷新 + LAN WebSocket 广播
删除 → FileOperationService.delete_to_trash
 └→ send2trash
 └→ _clear_deleted_projection（db_write_lock 内删 tags/meta + 删 .webp 文件 + 删索引）
 └→ FileDeleted + FileSystemChanged
撤销 → UndoService.perform_undo
 └→ prepare_delete 备份（undo 临时目录）→ FileOperationService.restore_backup
```

## 链路 4：浏览器访问 → 认证 → 文件下载

```
GET /browse
 └→ pages._spa_response（webui/dist/index.html，缺失 503）
浏览器随后 GET /api/info（公开）
 └→ 返回 principal/capabilities（前端决定 UI 形态）
GET /api/files?path=xxx
 └→ security_mw（限流豁免路径）→ auth_mw（token 链判定 → principal）
 └→ require_permission(browse) → validate_path（PathGuard）
 └→ AssetService.list_directory（asyncio.to_thread）
 └→ 响应 items[]（含缩略图 URL）
GET /api/download/{path}
 └→ require_permission(download) → PathGuard
 └→ 文件 → FileResponse；目录 → 估算大小（500MB 上限）→ build_zip_async（线程池）→ 临时 zip → 响应后自动删除
```

## 链路 5：分享链接 → 密码解锁 → 限次下载

```
桌面端（或 admin）POST /api/shares
 └→ require_permission(manage_links) → ShareService.create_share
      └→ 随机 id + 密码 PBKDF2 哈希 + expires_at + max_downloads → share_links 表
 └→ 返回 /s/{id} URL（QR 码显示）
访客打开 /s/{id} → ShareReceivePage → POST /api/shares/{id}/verify{password}
 └→ 校验 → generate_share_token（1h）→ set_share_cookie（path=/api/shares/{id}）
GET /api/shares/{id}/download/{path}
 └→ get_share_token（Cookie/Bearer）→ verify_token
 └→ 到期/限次检查 → _resolve_share_target（路径包含校验）
 └→ increment_download（原子计数）→ FileResponse
```

## 链路 6：启动 LAN 服务器 → 后台扫描 → 搜索

```
LanSharingMixin._toggle_sharing → ShareManager.start(runtime=...)
 └→ _LanServerImpl.__init__
      ├→ 校验 runtime 服务均绑定该 session（5 个服务 provider 指纹比对）
      ├→ AuthService/ShareService 创建（随机 token_secret）
      └→ LanScopedServices 捆绑（auth/meta/project/tag/search/thumb/asset/share + ActivityLog/OnlineUsers）
 └→ _run（后台线程 + 新事件循环）→ _startup
      ├→ ws_manager.start_accepting → auth/share 表初始化 → AppRunner/TCPSite
      ├→ 注册 runtime lifecycle adapter（库关闭时服务器先停）
      └→ scanner.start_background_scan（全库 os.walk 内存索引）
GET /api/search?q=...
 └→ require_permission(browse)
 └→ SearchService.search_by_name（内存索引）→ 空则 search_by_name_indexed（assets 表）
```

## 跨层一致性机制汇总

| 机制 | 位置 | 作用 |
|---|---|---|
| `session_token` 事件隔离 | context.py / runtime_events.py:199 | 多库并存时事件只影响本库 |
| `epoch + revision` 游标 | runtime.py | LAN 客户端检测缺失更新（admission barrier 补偿） |
| `db_write_lock` 串行写 | database.py:318 | 跨线程（GUI/worker/LAN）写安全 |
| `_assert_under_root` / `PathGuard` | 双端 | 文件路径逃逸防护 |
| mtime 失效缓存 | directory_cache / file_meta | 外部变更自愈（当前浏览目录有 QFileSystemWatcher 自动刷新，其余需重新进入） |
| `_measure_command` / 遥测 | file_operation_service.py:26 | 命令级性能观测 |
