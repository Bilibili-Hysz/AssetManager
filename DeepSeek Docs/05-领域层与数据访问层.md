# 05 · 领域层与数据访问层

## 1. 领域事件 `domain/events.py`

全部为冻结 dataclass，无基础设施依赖。两类事件并存：

| 类别 | 事件 | 说明 |
|---|---|---|
| 库级 | `LibraryOpened` | 库打开（library_root + session_token） |
| 文件级 | `FileRenamed/FileDeleted/FileCreated/FileCopied` | 无会话信息（遗留） |
| 会话级 | `FileSystemChanged` | **新投影体系核心**：library_root + session_token + kind + paths + old_paths |
| 标签 | `TagsChanged`（遗留）/ `AssetTagsChanged`（会话级）/ `TagCatalogChanged` | 会话级事件携带 token 供投影隔离 |
| 元数据 | `NotesChanged/UrlsChanged`（遗留）/ `AssetNotesChanged/AssetUrlsChanged`（会话级） | 同上 |

**双轨制说明**：遗留事件（无 session_token）仍被部分 UI 订阅；新事件（带 session_token）供 RuntimeEventRouter 做会话隔离。这是迁移中间态。

## 2. 事件总线 `domain/event_bus.py`

- `EventBus`：全局单例（`get_event_bus()`），`subscribe/unsubscribe/publish` 全线程安全
- `publish`：快照锁迭代 handler，**单个 handler 异常不影响其他 handler**（log 后继续）——隔离性设计
- `EventSubscription`：幂等 close；`subscribe_weak`：`WeakMethod` 包装，避免绑定方法阻止 GC（防泄漏）
- `clear()`：测试清理用

## 3. 领域错误 `domain/errors.py`

```
DomainError
├── PathEscapeError(path, root)     # 路径越界（LAN/文件操作安全）
├── MissingPathError(path)          # 路径不存在
├── DuplicateError(entity, key)
├── NotFoundError(entity, key)
├── ValidationError(field, message)
└── OperationNotPermitted(message)
```

注意：LAN 层有自己的 `lan/path_guard.py` 错误类型（PathGuardError 系，是 ValueError 子类），与领域层 PathEscapeError 并存——两套错误体系，属轻微重复设计。

- `is_path_allowed`（:58-71）：**normpath 折叠 `..` 后再做前缀匹配**，防 `project/../public.txt` 逃逸（注释明确说明此攻击面）
- `to_public_dict`：对外安全字典（不含 password_hash）

### `domain/auth.py` — 纯密码学
| 函数 | 算法 | 用途 |
|---|---|---|
| `hash_password` | PBKDF2-SHA256, 100k 迭代, 32B 盐 | 用户密码/分享密码 |
| `hash_key` | PBKDF2-SHA256, 50k 迭代, 16B 盐 | 访问密钥 |
| `verify_password/verify_key` | hmac.compare_digest 恒定时间比较 | — |
| `generate_token`（简单密码模式） | HMAC(ts) 截 32 位，24h 有效 | 单密码登录 |
| `verify_auth_token` | HMAC(ts, token_secret)，24h | 本地 UI（Qt 桌面）→ LAN 的 Bearer token |
| `generate_user_token` | `ts.user_id.sig`（签名覆盖 username/role），24h | 用户登录 |
| `generate_share_token` | `ts.sig`，**1h** | 分享密码解锁 |
| `validate_password_strength` | 8+/大小写/数字/特殊 + 弱密码黑名单 | 注册校验 |

## 5. Repository 层（7 个）

**统一模式**：构造收 `Connection`；写操作包 `db_write_lock(conn)`；批量查询分块（900/500）规避 SQLite 变量上限（999）。

### `tag_repository.py`
| 方法 | SQL 要点 |
|---|---|
| `get_tags` | 按 tag 排序 |
| `list_tags_with_counts` | GROUP BY + COUNT |
| `get_tags_for_files` | 分块 IN 查询（900/块） |
| `add_tag/remove_tag` | INSERT OR IGNORE / DELETE，单语句提交 |
| `delete_path`（:118-136） | **前缀删除**：LIKE ESCAPE '\\' 转义 `%_` 防注入，分隔符兼容 / 与 \ |
| `get_tags_for_tree` | 目录前缀 LIKE |
| `rename_tag/delete_tag` | UPDATE/DELETE 全表 |
| `migrate_path` | 路径迁移（INSERT OR IGNORE + 删除旧） |
| `get_tags_with_metadata` | file_tags LEFT JOIN tag_metadata |

### `metadata_repository.py`
- notes/urls CRUD（urls 是 JSON 数组文本列，`_decode_urls` 容错解析）
- 大小/文件数缓存：`get/set_cached_size`、`get/set_cached_file_count`、`batch_get/set_cached_file_counts`
- `get_library_total_size` / `set_library_total_size`（library_stats 表）
- `invalidate_size_cache` / `delete_path`（前缀删除）/ `migrate_path`（合并策略：notes 非空优先、urls 非 '[]' 优先）

### `share_repository.py`
- `share_links` 表惰性建表；`insert/get/list_all/delete/increment_download/get_password_hash`
- `get(include_unavailable)`：区分"正常/已过期/超限"（供管理界面显示）

### `auth_repository.py`
- `users` / `invite_codes` 表；用户 CRUD、`has_active_users`、`insert_user_with_invite`（事务性消耗邀请码）、邀请码管理

### `thumbnail_repository.py`
- `thumbnail_cache` 表：insert/query/get/list_all_with_metadata（baked 缩略图归属）/`delete_path`（返回受影响的 cache_key 供物理删文件）

### `asset_index_repository.py`
- `assets` 表：`replace_parent_entries`（按 parent 批量替换，upsert）、`query_by_parent/extension/search_by_name`、`delete_entry/delete_path`（前缀删）

### `plugin_metadata_repository.py`
- `plugin_metadata` 表：按 file_path 存插件字段（key-value），插件禁用后仍可显示

## 6. 数据流要点

```
UI/Route 调用
  └→ Application Service（session_operation 租约）
       └→ Repository（db_write_lock(conn) 串行写 / 直连读）
            └→ SQLite（WAL，每库一连接）
服务变更 → get_event_bus().publish(会话级事件)
  └→ RuntimeEventRouter（token 匹配 + 路径归一化）
       └→ InvalidationEvent(epoch, revision, domains, paths)
            ├→ LAN: WebSocket projection_invalidated 广播
            └→ (未来)桌面投影
```

**路径存储约定**：`file_tags/file_meta` 存 **resolve 后的绝对路径**（Windows 盘符大写规范）；LAN 侧对外一律转 `/` 相对路径。Windows 下 `\\` 与 `/` 混用的 LIKE 查询均做转义处理。
