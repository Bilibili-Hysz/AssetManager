# 07 · 桌面 UI 层

## 1. 主窗口 `window.py`（665 行）

`MainWindow(LanSharingMixin, QMainWindow)`（:40）：

### UI 结构
```
自定义菜单栏 QWidget（原生菜单隐藏）
├── QMenuBar：库/工具菜单（工具菜单含：外部工具、插件管理器、插件贡献、分享系统、快捷键）
├── WorkspaceSection：工作区标签（多库标签页切换，library_switched 信号）
└── 🌐 分享开关按钮
中央：QWidgetFileListPanel（文件列表）
左侧 dock：SidebarPanel（侧边栏）
右侧 dock：InfoPanel（信息面板）
底部：QStatusBar（分享状态指示，点击复制 URL）
```

### 关键机制
- **背景绘制**（paintEvent :110-146）：背景图 → 效果（模糊/马赛克）→ 按窗口缩放缓存（path→processed→scaled 三级缓存）；resize 150ms 防抖重绘
- **启动动画**：300ms 淡入
- **面板服务注入**（`_apply_scoped_services` :77-92）：每个会话切换时把 `LibraryScopedServices` 推给 file_list/info/sidebar/tag_tree
- **工作区切换**（`_on_switch_library` :396-398）→ `WindowLifecycleCoordinator.switch_library`（会话编排）
- **关闭语义**（closeEvent :651-665）：有托盘 → 最小化到托盘；真退出 → `_shutdown_resources()` → `library_service().close()`（优雅关全部库）
- 快捷键帮助、插件命令执行（`_run_plugin_command` :618-638）

## 7. 数据流要点

```
桌面操作数据流（读）：
侧边栏点击目录 → signal_bus.directory_changed → FileListPanel.navigate_to
  → FileSystemModel 后台扫描 → 行插入 → 可见项 → ThumbnailLoader 异步加载
  → 网格绘制；选中 → file_focused → InfoPanel.update_info（后台任务）→ 字段渲染

桌面操作数据流（写）：
信息面板编辑标签/备注 → InfoController → TagService/MetadataService
  → Repository（写锁）→ 领域事件 → RuntimeEventRouter → LAN 广播
文件右键操作 → ActionsMixin → FileOperationService → 事件 + 索引/元数据迁移
撤销/重做 → UndoService.perform_undo → FileOperationService（suppress 遥测）
```

**异步纪律**：Qt 主线程不碰磁盘/网络；所有扫描/缩略图/信息加载走 `QThreadPool`/`QRunnable` + 信号回主线程；代际（generation）机制防止过期任务结果覆盖新状态。
