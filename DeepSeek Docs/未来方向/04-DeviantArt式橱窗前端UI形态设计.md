# 04 · DA 式橱窗前端 UI 形态设计（DeviantArt 展示界面参考）

> **状态：🔵 设计参考（随店铺方向同批确认，暂不开发）**
> 本文聚焦"类 DeviantArt 的**展示前端 UI 形态**"：画廊网格、作品页排版、浏览交互、视觉语言。**不含任何社交功能**（评论/关注/消息已整体砍除，见决策记录）。

## 一、设计意图

DeviantArt 的展示 UI 是"**图片优先**"浏览心智的成熟样本：内容最大化、界面元素让位于作品、浏览成本趋近于零。橱窗化买家端直接借鉴其**形态**（非社区），配合店铺交易形成"逛画廊 → 看作品 → 购买"的流畅链路。

**为什么 DA 形态适合本产品**：素材资产（模型/贴图/插画）与 DA 的作品性质同构——买家需要"快速扫视大量视觉内容、点开细看、决定是否购买"，这正是画廊网格 + 作品页解决的问题。

## 二、形态特征分解（DA 界面语言）

### 1. 画廊网格（Gallery Grid）——买家端主视图

```
┌──────────────────────────────────────────────────────────┐
│  店面横幅（店名/公告）                                      │
│  [全部] [插画] [模型] [贴图] [热门]      🔍 搜索  ⚙ 排序    │  ← 分类栏
├──────────────────────────────────────────────────────────┤
│  ┌────────┐ ┌────────┐ ┌────────┐ ┌────────┐             │
│  │ ██████  │ │ ██████  │ │ ██████  │ │ ██████  │          │
│  │ ██████  │ │ ██████  │ │ ██████  │ │ ██████  │  网格：   │
│  │ ██████  │ │ ██████  │ │ ██████  │ │ ██████  │  统一裁剪 │
│  ├────────┤ ├────────┤ ├────────┤ ├────────┤  正方形     │
│  │ 作品名  │ │ 作品名  │ │ 作品名  │ │ 作品名  │           │
│  │ ¥25     │ │ 免费    │ │ ¥60    │ │ ¥12     │  ← 价格角标│
│  └────────┘ └────────┘ └────────┘ └────────┘             │
└──────────────────────────────────────────────────────────┘
```

**形态规则**：
| 元素 | 设计 | 映射现有组件 |
|---|---|---|
| 缩略图 | **统一裁剪比（正方形，object-fit: cover）**——网格整齐的关键 | ProjectGrid + 缩略图管线（useThumbnailCache） |
| 卡片 | 图片上缘无圆角（内容出血）、文字区轻量（名称一行 + 价格）、悬停浮层 | ProjectCard 改造 |
| 悬停交互 | 显示快速操作：收藏 ♥ / 购买 🛒 / 预览（透明度渐入） | 新增（hover overlay 模式参考桌面 _grid_widget 的 hover fade） |
| 价格角标 | 左下角小标签（免费 = 绿色"Free"）；无价格 = 不显示（兼容非商品目录） | ProjectCard 新增 prop |
| 加载 | 骨架网格（Skeleton 复用）+ 无限滚动（IntersectionObserver） | 新增 useInfiniteGrid hook |
| 分类栏 | 顶部横向标签栏（复用 FILTER_CATEGORY_LABELS：images/models/videos/...）+ 热门标签 | FileToolbar 简化版 |

### 2. 作品页（Artwork View）——买家端详情

```
┌────────────────────────────────────────────────────────────┐
│  ← 返回画廊   面包屑 > 分类 > 作品名                    [♥ 收藏]│
├──────────────────────────────────┬─────────────────────────┤
│                                  │  作品名                  │
│                                  │  作者 · 更新日期          │
│        大图预览区（深色画布）        │  ──────────────────────  │
│        最大可用尺寸 / 可缩放         │  描述（备注/URL）        │
│        上一篇 ◀ ▶ 下一篇           │  ──────────────────────  │
│                                  │  标签云（可点击过滤）      │
│                                  │  ──────────────────────  │
│                                  │  文件信息（格式/大小/数量） │
│                                  │  ──────────────────────  │
│                                  │  [🛒 购买 ¥25]   [下载]   │
│                                  │  （免费作品直接下载）       │
└──────────────────────────────────┴─────────────────────────┘
```

**形态规则**：
| 元素 | 设计 | 映射现有组件 |
|---|---|---|
| 大图区 | 深色画布（#020617 现有底色即符合）、图片居中自适应、点击全屏 | LayeredPreview / ImageViewer 复用 |
| 左右导航 | 键盘 ← → + 两侧箭头（现有 ImageViewer 已有 _nav 模式） | 新页面容器 |
| 右侧信息栏 | 桌面 ≥1024px 右侧固定栏；移动端折叠到图片下方 | 现有 DetailPage 的 InfoPanel 布局思路 |
| 标签云 | 点击 → 标签浏览页（零后端改动，tags API 已有） | TagChip 复用 |
| 购买/下载按钮 | 主按钮 = 购买（高对比 accent）；已购/免费 = 下载 | 新 |
| 布局优先级 | **作品图占 65-70% 宽度**，信息栏 30-35%——图片优先原则 | DetailPage 改造（现为左右均衡） |

### 3. 店面首页（Storefront Landing）

```
┌────────────────────────────────────────────────┐
│  店名 · 横幅（可选 logo/封面）                     │
│  公告（welcome_msg）                             │
│  ──────────────────────────────────────────     │
│  [热门标签云：插画 模型 贴图 场景 角色]             │  ← popular_tags
│  ──────────────────────────────────────────     │
│  精选（preview_pool 预览墙，横排滚动或大网格）       │  ← 现有 Gate 墙
│  ──────────────────────────────────────────     │
│  最新上架（按 mtime 倒序网格，4-8 个）             │  ← /api/home recent
└────────────────────────────────────────────────┘
```

现有 LandingPage Gate 墙直接升级：加店名/横幅/公告/标签云，其余保留。

### 4. 视觉语言（继承现有 token，不引入新设计系统）

| Token | 取值 | 说明 |
|---|---|---|
| 底色 | `--color-bg: #020617`（现有） | 深色画布天然符合图片优先 |
| 卡片 | `--color-surface: #0f172a` + 1px border + 悬停提升（shadow/scale 1.01） | 现有 slate 系 |
| 缩略图裁剪 | `aspect-ratio: 1/1; object-fit: cover` | 网格整齐的关键 |
| 留白 | 网格 gap 16-20px；画廊容器 max-width 1400px 居中 | DA 式大留白 |
| 文字 | 作品名 14px/500；价格 13px accent 色；辅助信息 muted | 现有 |
| 动效 | hover fade 150ms + reduced-motion 降级（现有惯例） | 桌面已实践 |

## 三、与现有 WebUI 的改动清单（增量，非重写）

| 现有 | 改动 | 新增 |
|---|---|---|
| LandingPage | 加店名/横幅/公告/标签云 | — |
| ProjectGrid / ProjectCard | 统一裁剪比、价格角标、悬停操作层、无限滚动 | useInfiniteGrid hook |
| DetailPage | 图片优先布局（65/35）、左右导航、标签云、购买/下载按钮 | — |
| FileToolbar | 简化为画廊分类栏 | — |
| ImageViewer | 复用（全屏预览） | — |
| TagChip | 复用（标签云） | — |
| Skeleton | 复用（网格骨架） | — |
| — | — | /store/gallery/:tag 标签浏览页（零后端改动） |
| — | — | 移动端：单列瀑布 + 底部操作栏（购买/收藏） |

**零后端改动的部分**：画廊网格、作品页布局、标签浏览、无限滚动、视觉 token——全部基于现有 API（`/api/home`、`/api/projects`、`/api/tags`、`/api/thumbnails`）。价格/购买/收藏属店铺开发阶段（S2/S3，见 03 文档）。

## 四、移动端形态（DA 移动端同原则）

- 画廊：单列瀑布（卡片 2 列 → 1 列随屏宽），缩略图仍正方形
- 作品页：图片全宽 + 信息折叠（手风琴），购买按钮**固定底部**（thumb-reach）
- 浏览：滑动为主，← → 键盘仅桌面
