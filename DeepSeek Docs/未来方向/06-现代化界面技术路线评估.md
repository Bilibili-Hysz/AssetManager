# 06 · 现代化界面技术路线评估（PySide6）

> **状态：🔵 决策参考（2026-07-31 确认路线）**
> 回答"PySide6 能否做现代界面"：**能，且 QSS 深化路线可达成 Fluent/Material 级 90%**。本文评估四条路线并给出本项目推荐。

## 一、直接结论

现代界面（Fluent/Material/现代暗色）与"传统 Qt 外观"的差距**不在技术栈，而在四件事**：层次（阴影/深浅）、图标体系、动效语言、细节密度——每一项 PySide6 都有成熟实现。本项目已具备 token 管线/缩放体系/自绘网格动效三大正确资产，**继续 QSS 深化即可达成现代化目标**，无需更换技术栈。

## 二、路线对比

| 路线 | 现代感上限 | 成本 | 本项目契合度 | 结论 |
|---|---|---|---|---|
| **QSS 深化（当前）** | ★★★★☆ | 低（5-7 周，见 05 规划） | ★★★★★ | ✅ **推荐** |
| QML（Qt Quick） | ★★★★★ | 高：UI 层重写 + QML 语言栈 + 主题系统重写为 QML 样式 | ★★☆☆☆ | ⏸ 远期选项，仅当追求极致特效 |
| 全自绘 | ★★★★★ | 极高：每控件手写绘制/交互/无障碍 | ★★☆☆☆ | ❌ 仅特殊控件（网格已用） |
| 第三方库（QFluentWidgets 等） | ★★★★☆ | 低（引入依赖） | ★★★☆☆ | ⚠️ 参考/局部选用 |
| Web 混合（QWebEngineView） | ★★★★★ | 极高 + 内存重 + 与 Qt 生态割裂 | ❌ | ❌ 否决（换技术栈） |

## 三、现代 UI 要素 → Qt 实现映射

| 现代要素 | Qt 实现 | 本项目落地（对应 05 规划） |
|---|---|---|
| 阴影/层次 | `QGraphicsDropShadowEffect`（blur 24 / offset(0,8) / rgba(0,0,0,0.35)），封装 `widgets/elevation.py`，仅套顶层容器 | P1-6 深度感 |
| 模糊背景（玻璃拟态） | Windows 11 DWM/Mica（Qt 6.5+ 实验 API）；低配用 `QGraphicsBlurEffect` | 背景已有 blur 效果（bg_effects.py） |
| 圆角/渐变 | QSS `border-radius` / `qlineargradient` 完全支持 | P0-3 圆角系统 |
| 图标 | SVG 集 + QPainter 按主题着色（alpha 通道） | P0-1 图标统一 |
| 动效 | `QPropertyAnimation` / `QSequentialAnimationGroup`（网格已证明可行，_grid_widget） | P1-7 对话框淡入等 |
| 字体 | 字阶系统 + 现代字体（Inter 等，需随包分发或系统字体回退） | P0-4 字阶系统 |
| 滚动条/输入细节 | QSS 伪状态全套（::handle:hover 等） | P1-5 样式补全 |
| 组件级动画 | `QGraphicsOpacityEffect` + 动画组合 | 网格已有模式，推广到面板 |

**关键认知**：微软官方的 Qt Fluent 组件库（QFluentWidgets，纯 PySide6 实现）证明"现代 Fluent 风格 = QSS + 少量自绘"，无需 QML。

## 四、QML 的客观评估（为什么不现在选）

| 维度 | 说明 |
|---|---|
| 能力 | GPU 渲染、着色器（blur/辉光）、状态机动画、物理弹簧——动效上限最高 |
| 代价 | ① 全部 UI 层重写为 QML ② 现有 22 主题 QSS 体系作废，重写为 QML 样式 ③ 双语言栈（Python + QML）维护 ④ 与现有面板/对话框代码混编（QQuickWidget 桥接）⑤ 200+ 桌面测试重写 |
| 收益 | 仅"特效上限"提升——对本产品（素材浏览工具，核心是网格性能与信息密度）边际价值低 |
| 判定 | ⏸ 仅当未来产品定位转向"展示型/消费型"（如橱窗店面风格要求极致视觉）时重新评估；当前保持 QSS |

## 五、第三方库参考

| 库 | 风格 | 建议 |
|---|---|---|
| QFluentWidgets | 微软 Fluent（PySide6 原生） | 参考其导航/卡片/开关的 QSS 写法；不整体引入（避免与自绘网格/主题系统耦合风险） |
| qt-material | Material QSS | 参考配色与控件规范 |
| QDarkStyleSheet | 暗色 QSS | 参考滚动条/输入框细节实现 |
| Qt 官方 examples/widgets | — | 截图遍历基准 |

## 六、推荐路线（结合 05 规划）

```
阶段一（V1）：图标系统 + 按钮变体 + 字阶     → 视觉印象 60%
阶段二（V2）：间距/圆角 token + 样式补全     → 一致性
阶段三（V3）：阴影封装 + 对话框统一 + 动效   → 现代感（层次 + 微动效）
全部基于既有 token 管线（themes.py properties + prop()）
```

**判定标准**（何时升级 QML）：当且仅当出现"桌面端需要玻璃拟态/复杂动效的品牌级要求"且现有 05 规划已全部落地仍不满足时。
