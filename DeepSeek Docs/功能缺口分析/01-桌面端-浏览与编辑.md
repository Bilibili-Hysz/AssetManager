# 01 · 桌面端：浏览与编辑功能缺口

覆盖：`panels/file_list/*`、`panels/image_viewer.py`、`panels/info.py`、`panels/sidebar.py`、`panels/tag_tree.py`、`controllers/*`

## G1-1 多选文件的批量操作（打标签/备注）[P1][M]

- **现状**：详情视图支持多选（`_selected_detail_paths` __init__.py:578），右键菜单有批量删除/复制/移动；但**标签与备注编辑仅支持单文件**——`InfoPanel` 一次只绑定一个文件（`update_info(info)` window.py:530），`InfoController.add_tag`（info_controller.py:142）逐文件操作
- **缺口**：无"选中 N 个文件 → 统一加标签/清标签/追加备注/清除备注"；`TagService.get_tags_for_files` 批量读已有（tag_service.py:63），但无对应批量写 UI
- **用户影响**：整理素材库最痛的操作之一（给一批截图统一打"参考"标签）只能逐个点
- **实现路径**：`TagService` 加 `add_tags_to_files(paths, tag)`（循环 `_publish_asset_tags_changed` 单事件批量）；文件列表右键菜单加"标签 → 批量添加/移除"子菜单；备注批量仅支持"追加前缀"避免覆盖冲突

> **部分已处理（2026-08-15 核实）**：批量标签 UI 已存在——右键「标签 → 应用标签/移除标签」(`_base.py:1361-1363`) 走 `_apply_tag_dialog(paths)`/`_remove_tag_dialog(paths)`（`_actions.py:650/663`）逐文件循环 `add_tag/remove_tag` 并刷新。剩余：① 备注批量「追加前缀」（未实现）；② 逐文件循环会逐条发 `AssetTagsChanged`，若要「单事件批量」可再加 `TagService.add_tags_to_files(paths, tag)` 优化（可选，性能项）。

## G1-2 媒体预览缺失（视频/音频/PDF/3D）[P1][XL]

- **现状**：`IMAGE_EXTS`（domain/asset.py:9）仅 9 种图片格式；`_grid_widget` 对非图片只画扩展名徽章（`_common.py` badge）；双击非图片文件 → `_on_file_double_clicked` 直接 `QDesktopServices.openUrl`（window.py:533）交给系统程序
- **缺口**：① 无视频缩略图（ffmpeg 抽取首帧，assets_filters.py:16 有 videos 分类但无渲染路径）② 无内置视频播放器 ③ PDF/文本无预览 ④ 3D 模型（.gltf/.glb/.blend）无预览
- **用户影响**：资产库面向 3D/素材人群，视频与模型预览是刚需；离开应用看文件破坏"就地检查"工作流
- **实现路径**：分两步——① 视频首帧缩略图（QMediaPlayer 截帧或 ffmpeg 子进程，S-M）② 视频双击改用 QMediaPlayer 内嵌播放（M）；PDF 用 QtPdf（PySide6 自带，M）；3D 模型预览优先级最低

> **部分已处理（2026-08-15，G1-2a）**：① 视频首帧缩略图已落地——`domain/asset.py` 新增 `VIDEO_EXTS`（.mp4/.mov/.avi/.mkv/.webm/.wmv）；`ThumbnailService.resolve()` 对视频走 `_extract_video_frame`（ffmpeg `-frames:v 1 -vf scale=512:512:force_original_aspect_ratio=decrease`，30s 超时，输出 `{cache_key}.jpg` 缓存）；LAN 缩略图路由已可服务视频首帧。桌面网格 `_loader.py` 的 `_load_image` 对 `VIDEO_EXTS` 走 `_load_video_frame`（经 `thumbnail_service.resolve` 取帧 + `QImageReader` 读入，`bake=False` 不重复烘焙），`_base.py` 缩略图请求条件由 `IMAGE_EXTS` 扩为 `IMAGE_EXTS | VIDEO_EXTS`。测试：`test_thumbnail_service.py` 3 例（ffmpeg 抽帧/缺失视频空结果/缓存复用，ffmpeg 不可用则 skip）+ `test_thumbnail_loader.py` 2 例（视频走服务取帧、无服务返回 None）。剩余：② 内置视频播放器（QMediaPlayer）、③ PDF/文本预览、④ 3D 模型预览（均不在本次 S-M 范围内）。

## G1-3 图片查看器功能过简 [P1][M]

- **现状**：`image_viewer.py` 有 适配/1:1/自由缩放（fit_in_view/reset_zoom :60-67）、滚轮缩放、平移、目录内上一张/下一张（`_nav` :211）、双击退出；**无**：幻灯片播放、旋转/镜像、保存/另存为、复制到剪贴板、EXIF/基本信息显示、缩略图导航条
- **缺口**：见上
- **用户影响**：素材筛选常用"自动播放看一圈"；旋转是快速判断构图方向的刚需
- **实现路径**：`_nav` 已有目录序列（`_build_image_list` :193）——加空格/方向键循环 + 定时器即得幻灯片（S）；旋转用 `QPixmap.transformed`（S）；状态栏显示文件名/尺寸/序号（S）

> **部分已处理（2026-08-15）**：已加幻灯片（空格切换 + 3s 定时器自动前进）与旋转（R / Shift+R，`QPixmap.transformed` + 累积角度），页脚提示同步更新三语；文件名/尺寸/序号本就在 header/footer 显示。测试 `tests/desktop/test_image_viewer.py` 新增幻灯片切换 + 旋转尺寸交换。剩余：保存/另存为、复制到剪贴板、EXIF 显示、缩略图导航条（后续 S-M 项）。

## G1-4 文件级收藏缺失 [P1][M]

- **现状**：侧边栏收藏是**目录收藏**（`SidebarFavorites` sidebar_favorites.py:14，favorites.json 存目录路径，支持重命名/图标/排序）；无文件级收藏
- **缺口**：无法把单个文件（不移动它）加入"收藏/稍后处理"列表；标签可部分替代但无"一键取回"入口
- **用户影响**：筛选素材时"标记感兴趣的单张"是高频心智模型
- **实现路径**：复用 `JsonStore` 新增 `file_favorites.json`（按库）+ 侧边栏第三虚拟节点（文件列表，点击 → 文件列表定位）+ InfoPanel 星星按钮；或最小方案：新标签语义约定

## G1-5 回收站管理界面缺失 [P2][M]

- **现状**：`delete_to_trash`（file_operation_service.py:280）走 `send2trash`（系统回收站），删除后**应用内无任何视图**查看/恢复；只能依赖系统回收站
- **缺口**：无"回收站"入口（恢复列表、彻底清空、恢复后元数据保留？恢复时元数据已随 `_clear_deleted_projection` 删除——恢复操作本身有 `restore_backup` 但那是撤销栈，不是回收站）
- **用户影响**：误删后找回路径不清晰（系统回收站中文件混在大量其他文件里）
- **实现路径**：① 最小：详情视图/右键"从回收站恢复"引导到系统回收站（S）② 完整：应用内回收站（移动到一个库内 `.trash/` 目录 + 元数据保留 + 过期自动清理，M-L）

## G1-6 搜索能力弱（无模糊/拼音/内容检索）[P1][L]

- **现状**：`matches_search`（asset_filters.py:111-115）仅**大小写不敏感子串**；`SearchService.search_by_name` 同样子串匹配；无拼音/首字母（素材人群常见"zs"→"僵尸"）、无多关键词 AND/OR、无文件名之外的内容搜索（PDF/文本全文）
- **缺口**：见上；Web 端同源（/api/search 同一服务）
- **用户影响**：大库检索是核心路径，子串匹配对中文文件名/跨语言命名低效
- **实现路径**：① 拼音：`pypinyin` 依赖 + 名称拼音索引列（M）② 多关键词：分词后 AND 过滤（S）③ 全文：SQLite FTS5 扩展表 + 增量索引（L，见 G3-2）

## G1-7 外部拖放导入无进度与目标选择 [P2][M]

- **现状**：`_on_drop`（_base.py:958-994）已实现外部导入：库内→移动、库外→复制；但：① 大目录 `copy_to_directory` 在后台线程执行无进度条 ② 目标固定为当前目录 ③ 同名文件静默改名（unique_destination）无确认 ④ 无"导入后标记"选项
- **缺口**：见上
- **实现路径**：`FileOperationService` 增加进度回调（每文件完成事件）；拖放时若按住 Ctrl 显示"选择目标目录"弹出；导入完成 Toast 汇总"成功 N/失败 M"

## G1-8 详情视图列定制缺失 [P2][S]

- **现状**：`DetailModel`（_detail_model.py:25）列固定（名称/大小/修改时间/类型）；插件系统有 `ColumnContribution`（host_context.py:81）但**无桌面 UI 配置列显隐/顺序/宽度记忆**
- **实现路径**：详情视图表头右键菜单（勾选显隐）+ 宽度持久化到 AppSettings（S）

## G1-9 网格视图辅助功能 [P2][S]

- **现状**：无选择模式复选框（需要 Ctrl 连续点选）、无"全选同类型"、无网格内嵌重命名确认框（重命名走对话框）
- **实现路径**：Shift 区间选择（如已支持则补文档）；双击文件名进入行内编辑（网格自绘已有 hit-test 基础）

## G1-10 侧边栏文件系统树缺失 [P2][M]

- **现状**：侧边栏是"库内目录树 + 收藏 + 最近"（sidebar.py:86），**无完整文件系统树**（库外浏览不可达）；`_root` 概念（_navigation.py:75-77）限制导航在库根内
- **用户影响**：查看库外文件（对比素材）需要另开资源管理器
- **实现路径**：侧边栏加"本机"虚拟节点（驱动器列表 + 懒加载树），导航到库外时文件列表降级为只读浏览模式

## G1-11 无文件冲突/去重检测 [P2][XL]

- **现状**：复制/移动同名自动改名（`unique_destination` file_operation_service.py:360-386），**无任何重复检测**（同名不同目录、内容哈希相同）
- **用户影响**：素材库重复下载是常见垃圾来源，手动清理成本高
- **实现路径**：新服务 `DuplicateService`：大小分组 → 哈希对比 → 重复列表 UI（保留/删除/移动）；AssetIndexService 已有 size 列可预筛（L-XL）

## G1-12 批量重命名预览与冲突处理 [P2][M]

- **现状**：`_batch_rename_dialog.py` 支持序号/正则，但无实时预览列表、无"目标名冲突"高亮、无撤销（批量重命名后仅能逐个 undo）
- **实现路径**：对话框加预览表格（原名→新名→冲突标记）+ 一次提交为单个 undo 条目（`record_rename` 支持批量变体）
