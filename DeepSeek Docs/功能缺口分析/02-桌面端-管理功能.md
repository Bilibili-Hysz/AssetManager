# 02 · 桌面端：管理功能缺口

覆盖：`dialogs/*`、`widgets/*`、`window.py`、`core/themes.py`、`core/settings.py`、`core/tool_scheduler.py`、`core/plugins/*`

## G2-1 标签颜色/图标/分类无编辑入口 [P1][S]

- **现状**：`tag_metadata` 表（db_migrations.py:87-99，v3 迁移）与 `TagService.set_tag_metadata`（tag_service.py:191）齐全，但 `set_tag_metadata` **无任何生产调用者**（rg 验证仅定义处）；`TagEditorDialog` 无颜色/图标控件；标签树只显示文本
- **缺口**：标签视觉化（颜色区分"授权/待处理/参考"）全链路在 DB 层存在、UI 层完全缺失
- **用户影响**：标签树在大库中纯文本难以快速定位；颜色是 Pixiv 式工作流的核心
- **实现路径**：TagEditorDialog 增加颜色（复用 `ColorPickerDialog` + HSVWheel）+ 图标（内置图标表）+ 分类输入 → 调 `set_tag_metadata`（S）；标签树/芯片渲染颜色（S）

> **已完成（2026-08-15，提交 `a775825`）**：新增 `dialogs/tag_style_dialog.py`（颜色 swatch 复用 `ColorPickerDialog` + 图标表复用 `icons.names()` + 分类输入，`saved` 信号）；`tag_tree.py` 标签图标按存储颜色着色（含主题刷新重着色）并在右键菜单加"编辑样式"入口；`TagTreeController` 暴露 color/category 并加 `get/set_tag_metadata`；`widgets/tag_chip.py` 的 `create_tag_chip` 支持按标签颜色着色，`info.py`/`TagEditorDialog` 经 `tag_color_from` 防御式取色；`desktop_ports.py` 端口补 `get_tag_metadata`；三语 i18n 新增 `tagstyle.*` + `tagtree.menu.style`。未闭合：标签树内分类分组/过滤展示（category 已入 `get_tag_with_files`，仅未渲染）可作后续小项。

## G2-2 无可视化主题编辑器 [P1][L]

- **现状**：`ThemePreviewDialog` 是**预览 + 另存为**（theme_preview_dialog.py:17），`create_custom_theme`（theme_loader.py:196）仅复制 JSON；修改颜色需手编 JSON 且无实时反馈（热重载存在：theme_loader.py:153-159 会刷新，但用户需自己改文件）
- **缺口**：无"设置 → 主题 → 编辑 token"的可视化编辑器（改色 → 实时预览 → 保存 U_ 主题）
- **用户影响**：主题定制是产品差异化卖点，但实际门槛高
- **实现路径**：新建 `ThemeEditorDialog`：左侧 token 列表（base/panel/accent/…+ 扩展 token）+ 右侧 ThemePreviewWidget 实时渲染 + 颜色选择器；`themes.invalidate_cache()` + `theme_changed` 信号驱动预览（L）

## G2-3 窗口布局不完整持久化 [P2][M]

- **现状**：仅保存 dock **宽度**（`_save_dock_layout` window.py:492-501，`dock_widths`）；**浮动/停靠位置、折叠状态、QSplitter 比例**不保存；重新打开后 dock 回到默认位置
- **实现路径**：`saveState()`/`restoreState()`（QMainWindow 原生支持）+ 折叠状态遍历（dock_factory 的 TitleBarWidget 有折叠按钮），存 AppSettings（M）

## G2-4 启动窗口引导不足 [P2][M]

- **现状**：`StartupWindow`（startup.py:292）展示库卡片列表 + 手动选择目录；无：① "新建库"向导（选择目录→命名→设置深度）② 库重命名（目录改名后库记录跟随）③ 库移除时"删除数据目录"选项 ④ 库数据占用大小显示
- **实现路径**：库卡片加右键菜单（重命名/移除/打开数据目录）；`LibraryManager` 加 update/remove 时清理 RuntimeData 确认（M）

## G2-5 工作区标签能力不足 [P2][S]

- **现状**：`WorkspaceBar`（workspace_bar.py:30）支持多库标签 + 持久化（`workspace_tabs` window.py:503-506）；无：拖拽排序、固定（pin）、中键关闭确认、最近关闭恢复
- **实现路径**：QTabBar 原生 setMovable + 中键处理（S）

## G2-6 设置不可迁移（无导出/导入）[P1][M]

- **现状**：`AppSettings`（settings.py）持久化到 `RuntimeData/Shared/settings.json`；无导出/导入入口；换机器/重装后主题、分享配置、UI 缩放、深度配置全部重设
- **缺口**：见上；连同 G6-1（库数据备份）一起考虑
- **实现路径**：设置对话框加"导出配置 JSON / 导入配置"（S-M）；建议同时打包：设置 + 自定义主题（U_*.json）+ 标签同义词库（tag_library.json）

## G2-7 缩略图缓存无自动治理 [P2][M]

- **现状**：`ThumbnailLoader` 磁盘 webp 缓存（.thumbnails/）**只增不减**；settings_dialog 有手动清理组（thumb_cache :507-529）；无：总量上限、LRU 自动清理、失效条目回收（源文件删除后的孤儿 webp 无人清——`_clear_deleted_projection` 只清理文件操作删除的，外部删除成孤儿）
- **实现路径**：① 启动时后台扫描 .thumbnails 与 thumbnail_cache 表对比清理孤儿（S）② 缓存目录大小上限 + 超限 LRU 清理（M）

## G2-8 快捷键不可配置 [P2][L]

- **现状**：`_shortcuts.py` + `_show_shortcuts`（window.py:574-596）硬编码；无自定义快捷键 UI、无冲突检测
- **实现路径**：QKeySequence 注册表 + 设置页"快捷键"Tab（L）

## G2-9 外部工具管理弱 [P2][S]

- **现状**：`tool_scheduler.py` 支持注册/运行（JSON 配置），但无管理 UI（增删改入口在分享设置之外？工具在"工具菜单"列出）；无参数模板（运行固定以当前路径为参数）、无输出集成
- **实现路径**：工具管理对话框（名称/命令/参数模板 {file}/{dir}/图标）；支持"输出到日志面板"（S-M）

## G2-10 插件生态缺口 [P2][L]

- **现状**：插件系统完善但：① **无插件市场/一键安装**（需手动拷贝目录到 Plugins/Addons/）② 无自动更新 ③ `permissions` 不强制（README 明示）④ 插件管理器（plugin_manager_dialog.py）无运行时错误/日志展示
- **实现路径**：① 最小：插件管理器加"从 zip 安装"（解压到 Addons + 校验清单，M）② 错误日志页签（S）

## G2-11 库统计不更新（总大小恒 0）[P1][S]

- **现状**：`set_library_total_size` 无生产调用者；`_schedule_library_stats_update` 基类空实现（_base.py:1151）；首页/信息面板 `total_size` 恒 0
- **实现路径**：`refresh_all`（window.py:556）或后台任务调 `MetadataService` 计算 + `set_library_total_size`；启动后延迟后台执行（S）

## G2-12 无命令行接口 [P2][L]

- **现状**：无 `python -m AssetsManager ...` 子命令；批量操作/脚本自动化只能走 GUI 或写插件
- **实现路径**：`AssetsManager/cli.py`：`list/tag/search/export` 子命令复用 Application 服务（L）；可作为未来自动化入口
