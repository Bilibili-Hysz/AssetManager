# 功能缺口分析 · 文档集

> 本套文档与 [主审计文档](../README.md) 配套：主审计回答"系统是什么、怎么运转"，本套回答"系统缺什么、该补什么"。
> 缺口按模块逐一分析，每条包含：现状证据（文件:行号）→ 缺口描述 → 用户影响 → 实现路径 → 优先级/工作量。
>
> 优先级：**P0**（立即，安全/数据/核心流程） / **P1**（近期，高频价值） / **P2**（可选，锦上添花）
> 工作量：S（≤1天） M（1-3天） L（1-2周） XL（≥2周）
