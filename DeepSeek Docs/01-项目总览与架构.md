# 01 · 项目总览与架构

## 1. 项目定位

AssetManager 是一个 **Python 桌面资产管理器 + 局域网分享服务器**：
- 桌面端（PySide6/Qt6）：管理本地文件资产库（浏览、标签、元数据、缩略图、撤销重做、主题、插件）
- LAN 端（aiohttp）：通过浏览器远程浏览/下载资产、创建分享链接、用户管理、Cloudflare 公网隧道
- Web 前端已从静态 HTML/JS 迁移为 **React 18 + Vite + TypeScript**（`webui/`），服务端渲染 SPA 入口

## 2. 分层架构

```
┌──────────────────────────────────────────────────────────────┐
│ Presentation   panels/ widgets/ dialogs/ window.py  lan/routes │  webui/(React)
├──────────────────────────────────────────────────────────────┤
│ Controllers   controllers/ (4 个纯逻辑控制器，无 Qt 依赖)        │
├──────────────────────────────────────────────────────────────┤
│ Application   application/ (14 个服务)  di/ (ServiceContainer)  │
├──────────────────────────────────────────────────────────────┤
│ Domain        domain/ (事件/错误/值对象/密码学)                  │
├──────────────────────────────────────────────────────────────┤
│ Infrastructure core/ (database, settings, themes, cache...)    │
│               repositories/ (7 个 Repository，SQL 封装)         │
└──────────────────────────────────────────────────────────────┘
```

架构原则（见 `docs/architecture.md`）：
- 依赖向下流动：Presentation → Application → Domain → Infrastructure
- 领域事件（`EventBus`）承担跨层通知；Qt 信号（`signal_bus`）承担 UI 内协调
- **LibrarySession 作用域**：每库一个服务绑定包（`LibraryScopedServices`），服务通过 `connection_provider` 获得本库 SQLite 连接，杜绝全局连接状态

## 5. 数据库 Schema（每库一个 `assetmanager.db`）

见 `core/database.py:_SCHEMA`（:27-72）与 `core/db_migrations.py`（v1~v5）：

| 表 | 用途 |
|---|---|
| `file_tags` | 文件→标签多对多（主键 file_path+tag，索引 tag） |
| `file_meta` | 备注 / URL JSON / 目录大小与文件数缓存 |
| `thumbnail_cache` | 缩略图磁盘缓存索引（cache_key + 源路径 + mtime） |
| `library_stats` | 库总大小/文件数/项目数 |
| `directory_cache` | 目录摘要缓存（item_count / preview_path / mtime）— v5 迁移 |
| `assets` | 懒填充的文件索引（v2 迁移，由 AssetIndexService 维护） |
| `tag_metadata` | 标签颜色/图标/分类（v3） |
| `plugin_metadata` | 插件解析的字段（v4） |
| `share_links` / `users` / `invite_codes` | LAN 分享/用户（由 AuthService/ShareService 惰性建表） |
| `schema_migrations` | 迁移版本记录 |

## 6. 数据目录布局（`core/path_resolver.py`）

```
RuntimeData/
├── Shared/                # 跨库共享：settings.json, tag_library.json, 插件目录
└── {库名}_{sha256[:10]}/  # 每库数据：assetmanager.db, favorites.json, recent.json
    └── .thumbnails/      # 缩略图 webp 缓存
Assets/Themes/             # 主题 JSON（D_暗色 / L_亮色 / U_自定义）
Plugins/Addons/            # 插件目录
webui/dist/                # React 构建产物（LAN SPA 静态资源）
```

关键设计：数据目录名 = 库 basename + 路径哈希，避免不同盘符同名库冲突；旧版（无哈希）目录自动迁移（`database.py:open_library` :67-70）。
