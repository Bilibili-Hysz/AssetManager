## 2. M0 时间驱动动画 tick（改造后的验证）

- animation_tick：1k 与 10k 均为 **p50 0.03–0.14ms / max 0.17ms**——与规模平坦（tick 只遍历活跃动画），M0 改造的规模目标达成

## 3. 规模热点（唯一）：model_reset

- 1k：p50 6.7ms / max 7ms
- 10k：**p50 34–35ms / p99 67–70ms / max 71ms**（线性于行数）
- 语义：切换目录时一次性代价（非每帧），70ms 顿挫在用户导航语境可接受；**登记 PF-3（P3 观察项）**——若未来要消除，方向是 reset 拆分或延迟非可见行清理

## 4. V18 规模验证（修复的规模化实证）

- 10k 行全选后单击（9,999 行反选）：`apply_selection_progress` **0.15ms**（阈值跳过生效，tweens/progress 均零）——修复前该操作为 O(N) tween 簿记 + 9 tick×10k 迭代 ≈150ms 掉帧窗

## 5. 结论

UI 渲染层**全面健康**：帧预算全达标且规模平坦，动画 tick 亚毫秒，唯一的规模热点（model_reset 70ms@10k）为导航一次性代价，登记观察。视觉统一阶段落地的 M0 时间模型与 V18 阈值跳过在本轮得到规模化实证。
