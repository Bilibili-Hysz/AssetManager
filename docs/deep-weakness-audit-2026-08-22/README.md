## 方法论

1. **领域拆分**：项目按结构拆为 8 个审计域（桌面 UI / 应用数据管线 / 应用领域服务 / 核心基础设施+插件 / 领域+仓库层 / LAN 服务器安全 / WebUI 前端 / 测试·门禁·CI·构建），每个域由一个独立深读审查执行：按行数排序完整精读最大模块，其余模块做针对性模式搜索 + 抽样精读。
2. **证据锚点**：每条发现必须有 `file:line` 锚点与代码证据；发现区分【确认】（读到代码即可证明）与【疑似】（需要运行时验证）。
3. **人工复核**：主审对各域报告中的 **11 条最高严重度发现逐条亲自读码复核，全部属实（零误报）**，复核项在各域文档中以「✓已复核」标记。
4. **宁缺毋滥**：只报有实际影响的薄弱项；风格问题不进入主要发现。
