# DeepSeek Docs 选择性迁移存档（2026-08-25）

## 背景与决策

`DeepSeek Docs/`（48 个 git 跟踪文件）是 2026-08 基线的审计/规划文档集，长期受"不改该目录"红线约束，其中服务数量、schema 版本等数字已明显漂移（见 `docs/full-review/06-audit-results.md` §2.5）。经登记 v2（`docs/full-review/evidence-register-v2-evidence-2026-08-25.md` §6）评估四个选项后确定方案 **B：选择性迁移**——把仍有独有信息价值、他处未见的内容逐字复制为带日期的存档副本；**原目录与其全部文件保持冻结不动**。

| 主题 | 选中文件 | 理由 |
|---|---|---|
| 功能缺口分析 | `README.md`、`07-优先级路线图.md` | README 是 65 条缺口（P0×6/P1×24/P2×35）统计与索引入口；07 是唯一聚合全部缺口的优先级矩阵，且 compose 系列外部引用最密集 |

## 使用注意

- 每份副本头部有 `[!NOTE]` 迁移横幅；正文为**逐字快照**，未做任何改写。
- 数字类断言（服务数、迁移表版本等）反映 2026-08 基线，现状以 `docs/architecture.md` 与 `docs/full-review/` 为准。

- 后续若决定原目录去留（删除/归档），应先在本文件登记决策再执行。
