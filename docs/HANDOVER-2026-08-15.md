## 1. 架构基线（承重墙，改动必须遵守）

- 五层：`ServiceContainer` DI → `ApplicationBootstrap` → `LibrarySession` → `LibraryRuntime` → `LibraryScopedServices`（LAN 投影 `_LanServicesHolder`）。WebUI 与桌面**共享同一套 application services**（`runtime_for(session)` 单例），桌面走进程内调用、WebUI 走进程内 aiohttp `/api/*` 包装同一实例。
- 五条边界规则：① application 参数/返回值禁止 URL/HTTP 语义 ② 表现层不持有 Connection/Repository ③ 优先进程内 ④ 校验只在服务层 ⑤ 各端只组装自己的服务。由 `scripts/check_boundaries.py`（门禁 1/2/3/5）+ `gen_ts_types.py --check` 强制。
- DB 迁移 append-only/frozen：`CURRENT_SCHEMA_VERSION=29`，v1–v28 不可改；`activity_log`(v29) 已做。

- 沙箱测试约束：`pytest -n 0` 且不传 `--basetemp`；**4 个 multiprocessing 命名管道测试必失败（EPERM）**，属环境限制不算回归；`test_dot_entries_and_files_are_ignored`（watcher mtime）与 `test_share_download_records_response_ready...` 偶发（时序）；symlink 相关在 Windows 跳过。
- `tmp_path` 走 `.pytest-tmp-paths/`（conftest 会话结束清理，偶有残留）。
- 沙箱 pwsh 是 ConstrainedLanguage：禁止 `[System.IO.*]::`、`Add-Type`、反射；捕获子进程 stdout（pipe）会 EPERM，`stdio: inherit/ignore` 可以。
