## 二、改进方案（按 ROI 排序）

### P0-1 图标系统统一（最高 ROI，1-2 周）

- **方案**：集成 SVG 图标集（推荐 **Phosphor** 或 **Lucide**——Lucide 为 ISC 许可可商用，且 WebUI 已用 lucide-react，**两端图标同源**）
- 实现：`core/icons.py`（图标名 → QIcon 缓存，读取 `assets/icons/{name}.svg`）+ `QIcon` 主题色化（QPainter 着色 alpha 通道，随主题 accent 变化）
- 替换点：window.py 的 🌐🔧🧩、workspace_bar、dock 标题按钮、右键菜单图标、空状态图标
- **验收**：全 UI 无 emoji；图标随主题色变化；WebUI 与桌面图标集同源（共用 `assets/icons/`，Web 端由 lucide-react 按名引用同一命名表）

### P0-2 按钮变体系统（2-3 天）

在 themes.py 的 QSS 中按 objectName 定义四态：

| 变体 | 样式 | 用途 |
|---|---|---|
| primary | accent 实色 + on_accent 文字（现状） | 主行动（购买/保存/确定） |
| secondary | panel 底 + border + body 文字 | 次要行动（取消/浏览） |
| ghost | 透明底 + 悬停 10% overlay | 工具栏/行内操作 |
| danger | danger token 实色 | 破坏性操作（删除） |

实现：`themes.py` 生成 `.btn-primary/.btn-secondary/.btn-ghost/.btn-danger` 类选择器；控件按语义设置 objectName。**同时激活 success/warning/danger token 的 UI 使用**（当前定义了但几乎未用）。

### P0-3 间距与圆角系统（2-3 天）

- 在 theme properties 中新增：`spacing`（xs 2/sm 4/md 8/lg 16/xl 24）、`radius`（sm 4/md 6/lg 10/xl 14——lg/xl 用于对话框与浮层）
- QSS 中所有 padding/margin 改为引用 `themes.prop()`（消除魔法数字）
- 面板内容 padding 4px → 8-12px；dock 标题 5px 10px → 8px 12px

### P0-4 字阶系统（1-2 天）

| 阶 | 尺寸 | 字重 | 用途 |
|---|---|---|---|
| caption | 8pt（原 6pt 徽章 → 8pt 或删除） | 600 | 徽章/辅助 |
| body | 10pt | 400 | 默认 |
| title | 12pt | 600 | 节标题 |
| heading | 14pt | 700 | 面板标题 |

全 QSS 删除硬编码 `font-size: 12px`，统一 `scaled_pt()`。

### P1-5 样式覆盖补全（1 周）

按控件清单逐项补全：`QTableWidget`（详情视图：行高 28px、无网格线、选中行 accent 10% 底）、`QSpinBox/QDoubleSpinBox` 箭头、`QCheckBox/QRadioButton` 指示器（SVG 对勾）、`QProgressBar`（accent 填充 + 圆角）、`QToolTip`（现有 tooltip_bg）、`QMessageBox` 按钮对齐。**验收：截图遍历全部控件无 Qt 原生样貌残留**。

### P1-6 深度感（3-5 天）

- 对话框/浮层：`QGraphicsDropShadowEffect`（blur 24, offset 0/8, color rgba(0,0,0,0.35)）统一封装为 `widgets/elevation.py` 的 `apply_elevation(widget, level)`
- 卡片（启动窗口库卡片、信息面板区块）：阴影 + 悬停 1.01 缩放（启动卡片已有 hover 提升则统一）
- 注意：阴影性能（仅顶层容器，不套在滚动内容上）

### P1-7 对话框视觉统一（1 周）

- `TabbedDialog` 基类：补全内部控件样式继承 + 对话框级联主题刷新（现主窗口有 `_on_theme_refresh` 但对话框是 exec 快照）
- 对话框标题栏复用 TitleBarWidget（非原生标题栏），圆角 lg + 阴影
- 动效：对话框淡入 150ms（现有主窗口 300ms 淡入同模式）

### P2-8 主题质量校验（2-3 天）

- 用现有 `contrast_ratio`（color_utils.py:84）批量校验 22 套主题的必选 token 对比度（WCAG AA：正文 4.5:1），不合格主题在主题选择器标注警告
- 检查 6pt 徽章在浅色主题（L_*）下的可读性

### P2-9 空状态与引导（1-2 天）

- 空库/空目录/无搜索结果三态：图标（新图标系统）+ 一句话 + 行动按钮（"拖入文件开始"）——降低"白板恐惧"
