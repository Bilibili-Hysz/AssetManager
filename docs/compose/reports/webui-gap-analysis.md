# WebUI 功能对比报告：老 WebUI vs 新 WebUI

## 1. 页面路由

| 页面 | 老 WebUI | 新 WebUI | 状态 |
|------|----------|----------|------|
| `/` 首页/Landing | ✅ 三栏布局，显示项目网格 | ✅ LandingPage 欢迎页 | ✅ |
| `/browse` 浏览页 | ❌ 无此路由 | ✅ BrowsePage（三栏布局） | ✅ 新增 |
| `/detail` 详情页 | ✅ 独立 detail.html | ✅ DetailPage | ✅ |
| `/login` 登录页 | ✅ 独立 login.html，有登录/注册/访客模式 | ✅ LoginPage（占位，未实现） | ❌ 未实现 |
| `/s/{id}` 分享页 | ✅ 独立 share.html | ✅ ShareReceivePage | ✅ |

## 2. 功能缺失清单

### 2.1 严重缺失（影响核心体验）

| 功能 | 老 WebUI | 新 WebUI | 优先级 |
|------|----------|----------|--------|
| **登录页面** | 完整登录/注册/访客模式/密钥模式 | 空壳页面 "Login form coming soon" | 🔴 P0 |
| **认证流程** | 用户名密码、访问密钥、访客模式 | 只有 token 管理，无登录 UI | 🔴 P0 |
| **注册流程** | 用户名/密码/邀请码/密码强度验证 | 无 | 🔴 P0 |
| **访客模式** | 点击"以访客身份浏览"直接进入 | 无 | 🔴 P0 |
| **分享链接创建** | 完整对话框（密码/过期/限次/预览） | ✅ ShareDialog 已实现 | ✅ |
| **分享链接管理** | 列表、删除、查看 | 无 | 🟡 P1 |
| **用户管理** | 用户列表、启用/禁用 | ✅ UserManagement 已实现 | ✅ |
| **邀请码管理** | 生成、撤销、列表 | ✅ InviteManagement 已实现 | ✅ |
| **活动日志** | 查看最近活动 | ✅ ActivityLog 已实现 | ✅ |
| **在线用户** | 查看在线用户 | ✅ OnlineUsers 已实现 | ✅ |

### 2.2 中等缺失（P1）

| 功能 | 老 WebUI | 新 WebUI | 优先级 |
|------|----------|----------|--------|
| **右键菜单** | Open/Download/Share/Copy Path/Copy Link/Details | 有 ContextMenu 组件，BrowsePage 中只实现了 Download/Copy Path/Open | 🟡 P1 |
| **打开项目详情页** | 双击文件夹进入详情页 | 只在 BrowsePage 中双击导航到子目录，没有进入详情页的入口 | 🟡 P1 |
| **标签过滤** | 点击标签过滤项目 | 无 | 🟡 P1 |
| **标签显示** | 项目卡片上显示标签（最多4个+N） | 无 | 🟡 P1 |
| **信息面板** | 显示元数据/标签/备注/URL | ✅ InfoPanel 已实现 | ✅ |
| **信息面板内容** | 选中文件时显示完整信息 | BrowsePage 中硬编码 `metadata={null}` 未使用 | 🟡 P1 |
| **批量下载** | 选择模式 + 批量下载按钮 | 工具栏有 Selected 按钮，但选择模式交互不完整 | 🟡 P1 |
| **下载进度** | 批量下载时显示进度条 | 无 | 🟡 P1 |
| **WebSocket 实时更新** | 指数退避重连，接收文件变更 | ✅ useWebSocket 已实现，但未在 BrowsePage 中使用 | 🟡 P1 |

## 3. 优先级修复计划

### P0: 必须立即修复
1. LoginPage — 实现完整登录/注册/访客/密钥模式
2. 认证流程 — 连接 AuthContext 到登录页面

### P1: 核心功能补齐
1. BrowsePage 信息面板 — 连接选中文件时获取元数据
2. 右键菜单 — 增加"详情"入口
3. 标签显示/过滤 — 在卡片和网格中显示标签
4. WebSocket 集成 — 在 BrowsePage 中使用 useWebSocket

### P2: 体验优化
1. 侧边栏可调整宽度
2. 快捷键 `/` 聚焦搜索
3. 移动端布局适配
4. 状态持久化
